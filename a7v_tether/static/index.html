    Kamera einrichten

    Selbsttest

      1. WLAN verbinden

        An der α7 V: Menü → Netzwerk → Wi-Fi → Zugangspunkt-Einstellungen und dasselbe WLAN wählen, in dem dieser Rechner ist. 5 GHz ist deutlich schneller.

        Kein Router vor Ort? Den mobilen Hotspot des Laptops einschalten und die Kamera damit verbinden.

      2. FTP-Server eintragen

        Menü → Netzwerk → FTP-Übertragungsfunktion → Servereinstellung → Server 1

      3. Root-Zertifikat importieren (FTPS)

        cacert.pem herunterladen

        Die Datei in das Hauptverzeichnis der Speicherkarte kopieren, Karte einsetzen und an der Kamera Netzwerk → … → Root-Zertifikat importieren wählen. Danach in der Servereinstellung Sicheres Protokoll: Ein setzen.

      4. Automatische Übertragung einschalten

        • FTP-Funktion: Ein
        • Autom. FTP-Übertragung: Ein – jedes Bild wird direkt nach der Aufnahme gesendet
        • Zu übertragender Dateityp: RAW, JPEG/HEIF oder RAW+JPEG
        • Energiesparmodus beim Shooting verlängern, damit das WLAN nicht abschaltet

      5. Lightroom Classic vorbereiten

        1. Datei → Automatisch importieren → Einstellungen für automatischen Import …
        2. Überwachter Ordner:
        3. Ziel, Dateibenennung, Entwicklungs-Preset und Stichwörter nach Wunsch wählen
        4. Datei → Automatisch importieren → Automatischen Import aktivieren anhaken

        Diese App erkennt, ob Lightroom die Bilder abholt, und warnt dich, wenn nicht.
